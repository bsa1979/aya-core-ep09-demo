# Proyecto de práctica · Bitácora

Portfolio ficticio, estático y no comercial para aprender el flujo de Git y GitHub Pages.

## Archivos

- `index.html`: contenido y estructura semántica de la página.
- `styles.css`: diseño adaptable, sin bibliotecas ni solicitudes externas.
- `.gitignore`: archivos locales que Git debe dejar fuera si aún no los sigue.

Abre `index.html` directamente en un navegador para previsualizarlo. El CSS usa fuentes del sistema; la web funciona sin conexión y no contiene formularios, cuentas, pagos, datos personales ni secretos.

Este ejemplo no está publicado. Sigue la guía paso a paso, revisa la visibilidad y las condiciones vigentes del alojamiento, y decide tú si y dónde publicas una copia propia. No uses GitHub Pages gratuito para una tienda, negocio en línea o SaaS comercial.
